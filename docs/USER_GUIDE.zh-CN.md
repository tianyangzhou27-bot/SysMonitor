# 使用说明

[English](USER_GUIDE.md) · [首页](../README.zh-CN.md) · [更新与下载](../updates/README.md)

适用：2026-11-13 发布快照（程序内部版本仍为 0.1.0）。界面目前为中文。

## 下载与启动

1. 前往 [GitHub Releases](https://github.com/tianyangzhou27-bot/SysMonitor/releases)，下载 `SysMonitor-*-windows-x64.zip`。GitHub 自动提供的 Source code 压缩包是代码，不是可直接运行的 Windows 软件包。
2. 将整个压缩包解压到有写入权限的目录，保留所有 DLL、`locales` 和 `resources` 文件夹。
3. 双击 `SysMonitor.exe`。通常无需管理员运行。关窗默认缩到托盘；完全退出请右键托盘图标并选择退出。
4. 首次出现 Telegram 设置窗口时，不需要此功能可直接关闭，不填写 Token。

系统要求：Windows 10/11 x64。进程采集助手依赖 Windows .NET Framework 4.8；若无法启动，请检查系统 .NET Framework 安装情况。部分硬件传感器还需单独运行 LibreHardwareMonitor。

## 查看监控与历史

- 主窗口查看 CPU、GPU、内存、磁盘、网络、温度与功耗；任务栏浮窗提供简要指标。
- 设置中调整刷新、浮窗、告警阈值、持续时间、冷却间隔及历史记录选项。
- 历史记录默认开启，可在设置中关闭或清空；关闭记录不会删除旧记录。历史页可导出 CSV。
- 未读取到的温度或功耗显示不可用，不代表 0。整机功耗可能为估算；累计电量只统计有有效采样的时段，不补算休眠、程序退出或缺失采样的时间。
- 网络测速需要手动启动，会产生较大下载流量；Cloudflare 模式也会上传测试流量。

## 进程管理

右键托盘图标 → **进程管理**。可按进程名/PID 搜索，按 CPU、内存、GPU、显存、网络或 I/O 排序，查看详情、打开文件位置，或确认后结束单个进程。

结束进程会丢失该进程未保存的数据。系统关键进程与程序自身受保护；权限不足时部分详情不可用。单进程网络依赖 ETW 权限；显示不可用时不能把它理解为零流量，也不要把代理进程和应用进程的流量重复相加。

## 温度、风扇与帧率

如需更多温度传感器，可单独以管理员身份运行 LibreHardwareMonitor，启用 Options → Remote Web Server → Run。程序读取本机 `127.0.0.1:8085`。硬件支持因设备不同而异。服务离线时，程序可能尝试启动已有的同名计划任务。

风扇默认交给固件。调整前请核对风扇角色，尤其不要将水泵当作普通风扇。PresentMon 帧率采集需要相应性能日志权限，详见[原有功能说明](FEATURES.zh-CN.md)。

## Telegram（可选，会向 Telegram 发送数据）

1. 托盘菜单 → **Telegram 报警设置**。在 Telegram 向 `@BotFather` 发送 `/newbot` 创建专用机器人；再向自己的机器人发送 `/start`。
2. 填入 Bot Token；必要时填自己的 HTTP/SOCKS5 代理地址，留空使用系统代理。Token 使用 Electron safeStorage 加密后保存在本机。
3. 点击“保存并读取私聊”，选择自己的私聊或填写 Chat ID。读取私聊本身会联网。
4. 根据需要开启“Telegram 报警推送”及“TG 私聊指令查询”。两者是独立开关；指令查询默认勾选，保存 Token 和 Chat ID 前请检查。报警还需要程序告警总开关开启。
5. “保存并发送测试”会发送电脑名称及时间；“发送状态报告”会立即发送状态，即使未开启自动推送也会执行。

发送 `/menu` 使用按钮菜单；`/status` 查看总览，`/top cpu`、`/top gpu`、`/top memory` 查看进程排行，`/power` 查看功耗电量，`/network` 查看网络，`/help` 查看帮助。菜单也提供温度和告警设置；绑定私聊中的告警设置操作可改变本机告警配置。

发送内容可能包括电脑名称、硬件型号、负载、温度、功耗、电量、进程名称及占用、本地/公网 IP、网关、DNS、代理路由及节点名称。发送后数据也会由 Telegram 及消息接收端处理、保存。不要公开 Token、Chat ID、数据库或带个人信息的截图。

若不希望 Telegram 后台联网，请关闭并保存推送和指令查询两个开关，且不要点击读取私聊、测试或发送报告。关闭 Telegram 不会关闭程序自身的公网 IP 查询及连通性检测。详见[隐私说明](PERMISSIONS_AND_PRIVACY.zh-CN.md)。

## 更新与排障

完全退出程序，备份本地用户数据，将新版解压到新目录后启动。不要在运行时覆盖 DLL。保留旧版便于回退；数据格式若有变化，应按该版本发布说明操作。Token 不能假定可跨 Windows 账户或电脑迁移。

设置和历史一般位于 `%APPDATA%\sys-monitor`；实际路径可能随安装方式变化。找不到时在 `%APPDATA%` 下查找 SysMonitor 对应目录。传感器缺失请检查硬件服务；Telegram 失败请检查代理、Token、私聊绑定以及是否有其他程序占用同一个机器人。提交问题前请删除个人数据。
