# 功能与使用指南

适用版本：仓库中的 SysMonitor 0.1.0 提取版。最后核对：2026-10-21。

## 软件用途

SysMonitor 是面向 Windows 桌面的本机状态监视器。它把硬件负载、网络状态和近期性能变化集中到一个窗口，并能在任务栏显示关键数字。它适合排查卡顿、观察温度与负载、回看性能变化；显示的“整机功耗”是估算值，不等同于插座功率计的实测值。

## 实际观察到的界面

在一台已有的 Windows 安装实例中打开主窗口、设置和历史页面，观察到：

| 区域 | 可见内容与用途 |
| --- | --- |
| 概览卡片 | CPU、GPU、内存、估算整机功耗，附实时曲线及状态提示。 |
| 网络 | 网卡及上下行速率、网关延迟、DNS、公网 IP；有代理/VPN 客户端、连接与节点信息面板。 |
| 进程与存储 | 进程资源占用排行、磁盘活动与硬件资料。 |
| 诊断与提醒 | 性能瓶颈判断以及可配置阈值提醒。 |
| 历史记录 | 按时间范围查看曲线，选取最多八个指标；可查看事件、导出 CSV 或清空本地历史。 |
| 设置 | 刷新间隔、任务栏指标、开机启动、关闭到托盘、历史保留、提醒、帧率采集和散热配置。 |

界面目前为中文。不同设备的传感器、显卡驱动和网络环境不同，卡片可能缺少部分数据。上述是界面观察，不代表每项可选功能都已经在这台机器上实际执行过。

## 开始使用

1. 按 [中文首页](../README.zh-CN.md#系统要求与运行方法) 安装并运行。首次打开后检查 CPU、GPU、内存及网络卡片是否出现数据。
2. 在设置中按需要选择任务栏指标和采样周期。数值越频繁更新，后台采样开销通常越大。
3. 通过顶部的历史入口查看过去的曲线；历史默认开启。若不需要保留本机记录，可在设置中关闭并清空已有数据。
4. 如需帧率数据，再配置 PresentMon 所需的 Windows 用户组权限；如需更多传感器或风扇调节，再单独配置 LibreHardwareMonitor。两者不是基础监控的前提。
5. 关闭主窗口默认只是隐藏到托盘；从托盘菜单选择退出才会完全停止程序。

## 功能边界

- 功耗卡片把已取得的 CPU、GPU 功耗与“其他硬件功耗”设置值相加，属于估算；可在设置中调整后者。不能把它当作电费或电源容量的精确依据。
- 国内外公网 IP 查询会自动访问外部服务；网络测速须由用户主动开始。测速可能消耗大量流量，详见 [权限与隐私](PERMISSIONS_AND_PRIVACY.zh-CN.md)。
- 代理/VPN 面板用于观察本机代理客户端及连接状态；本次代码审阅未发现它修改系统代理配置的调用。
- 帧率功能依赖 PresentMon 和当前账户权限，默认设置为“全屏”采集模式。没有权限时界面会提示。
- 更多温度和风扇控制依赖另行运行的 LibreHardwareMonitor 服务。默认风扇模式交由 BIOS/显卡管理；切换模式前应确认通道对应的硬件，尤其不要把水泵当作普通风扇。
- 历史数据库默认保存 24 小时高精度数据、7 天分钟汇总、30 天事件，设置的默认上限为 500 MB。容量控制代码是周期性维护，不能保证文件任何时刻都严格不超过该值。

## 验证范围

本次在现有 Windows 实例中只查看了主窗口、设置与历史页面；没有改变设置、启动风扇控制、运行测速、导出个人数据或公开包含真实设备信息的截图。当前环境没有可用的 Windows Sandbox、Hyper-V 虚拟机或 Docker，因此未完成独立虚拟机测试。功能细节和权限说明还结合了本仓库的生成代码与 PowerShell 辅助脚本审阅；这不是完整的安全审计。原始工程缺失的情况见 [源码说明](../recovered-src/README.md)。
