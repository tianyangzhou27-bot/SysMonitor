# 权限、数据与隐私说明

适用版本：SysMonitor 0.1.0 提取版；代码核对日期：2026-10-21。本说明记录程序**实际调用的能力**及其触发条件，不构成对所有依赖项的独立安全认证。

## 一眼看懂

- 基础监控通常以当前 Windows 用户身份运行；本次审阅未发现程序启动时主动请求 UAC 管理员权限的代码。
- 它会读取系统与硬件状态、进程及网络连接信息，并默认把性能历史写在当前用户的本地应用数据目录。
- 它**默认自动联网**查询公网 IP 和探测连通性。若需要完全离线使用，不能只依靠“不点测速”；应通过系统防火墙阻止联网，并预期相关卡片显示不完整。
- 只有启用可选功能时，才需要为 PresentMon 配置性能日志用户组，或另行以管理员身份运行 LibreHardwareMonitor。风扇写入可能实际改变转速。

## Windows 能力与触发条件

| 能力 | 用途与可能接触的数据 | 触发/权限 |
| --- | --- | --- |
| 系统性能计数器、硬件 API、PowerShell CIM/WMI | CPU/GPU/内存/磁盘负载、温度、设备型号、主板/BIOS、显示器和磁盘序列号等硬件元数据。使用 `systeminformation`、`nvidia-smi`、PowerShell/PDH；是否能读取取决于设备和 Windows 权限。 | 基础采样自动运行；通常为当前用户读取权限。PowerShell 辅助脚本以 `-ExecutionPolicy Bypass` 启动，作用于该次脚本进程。 |
| 进程与网络连接列表 | 通过 `tasklist`、`netstat` 和性能计数器读取进程名、PID、资源占用、连接地址/端口；可用于进程排行和代理面板。 | 监控时自动读取；部分受保护进程可能不可见。 |
| 网卡、Wi‑Fi、路由与 DNS | 读取本地 IP、网关、DNS、SSID、信号强度、网卡速度；读取当前用户的 Windows Internet Settings 代理注册表键。 | 网络面板自动刷新；未发现修改系统代理的调用。 |
| 用户应用数据目录 | `settings.json` 保存设置；`history.db` 为 SQLite 历史数据库，含指标、提醒/诊断事件，事件可能包含相关进程名。CSV 只在用户选择导出时写到指定路径。 | 历史默认开启；可在设置中关闭和清空。关闭记录不会自动删除旧记录，请另行清空。 |
| 登录启动项与托盘 | 通过 Electron 的 `setLoginItemSettings` 为**打包版**配置开机启动；窗口默认关闭到托盘。 | 开机启动默认关闭；在设置中选择后才配置。关闭窗口不等于退出。 |
| 性能事件跟踪 | 随附的 Intel PresentMon 捕获帧时间与关联进程信息。 | 帧率选项默认开启且设为全屏模式；实际采集需要相应权限。可能需要管理员把账户加入 Windows `Performance Log Users` 组并重新登录，SysMonitor 本身无需因此始终以管理员运行。 |
| 本地硬件服务 | 读取 `http://127.0.0.1:8085/data.json` 和传感器值；风扇设置通过 `/Sensor?action=Set` 写入。服务离线时程序会尝试运行**现有**名为 `LibreHardwareMonitor` 的计划任务。 | 需要用户另外运行并配置 LibreHardwareMonitor；它常需管理员权限访问某些传感器。风扇默认由固件控制，切换到手动/自动控制还需在界面确认。 |

## 外部网络连接

以下连接由主进程代码直接定义。目标站点能够看到发起请求的公网 IP 和常规连接元数据；若使用代理，看到的可能是代理出口 IP。

| 何时 | 目标 | 用途与流量 |
| --- | --- | --- |
| 启动后并约每 60 秒 | `ip.3322.net`，失败时 `myip.ipip.net`；`1.1.1.1/cdn-cgi/trace`，失败时 `api.ipify.org` | 查询两路公网 IP 与区域。 |
| 启动后并约每 5 秒 | 当前默认网关（ICMP ping）；`223.5.5.5:443`（TCP 建连） | 判断局域网和互联网连通性、估算延迟。 |
| 用户主动开始测速 | `speed.cloudflare.com` 或 `mirrors.cloud.tencent.com`、`mirrors.163.com`、`mirrors.tuna.tsinghua.edu.cn`、`mirror.nju.edu.cn` | Cloudflare 模式有下载与上传；国内镜像模式仅下载。可能产生大量流量，也可能经代理计费。 |
| 本机可选集成 | `127.0.0.1:8085`、本地 Clash/mihomo 控制接口/命名管道 | 读取传感器或本地代理状态；风扇控制会写入本地传感器接口。 |

本次对已提交应用代码的定向审阅未找到单独的账号、云同步或应用遥测上传服务；这不等于对每个依赖或所有网络环境作出“绝不传输”的保证。公网 IP 检查和连通性探测确实是自动网络活动。

## 本地数据管理与安全提示

在 `%APPDATA%` 下查找 `sys-monitor` / `SysMonitor` 对应的 Electron 用户数据目录，可定位 `settings.json`、`history.db` 及 SQLite 的临时文件。实际目录可因系统和安装方式不同而变化。设置页可以关闭历史记录、调整保留期限、清空记录；历史页导出 CSV 时请自行选择安全保存位置。导出的 CSV、数据库以及截图可能含设备型号、进程名、网络信息或代理节点名称，**不要直接上传到公开 issue**。

当前提供的 Windows 可执行文件未见 Authenticode 数字签名。仓库没有提供可从原始 TypeScript/React 工程重现该安装包的完整构建链；`recovered-src/` 是生成代码的拆分片段。请从可信来源取得软件，查看源码并按需限制网络访问。第三方组件见 [声明](../THIRD_PARTY_NOTICES.md)。
