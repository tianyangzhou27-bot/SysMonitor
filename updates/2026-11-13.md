# v0.1.0-20261113.1 · 2026-11-13

## 中文

同步当前 Windows 程序快照：进程管理、CPU/GPU/内存排行、硬件温度显示、Telegram 报警与恢复提醒、按钮菜单、状态/网络/用电查询和告警设置，以及界面外观与退出逻辑改进。

新增中英文使用说明和独立更新下载入口。隐私说明补充 Telegram 发送字段、独立开关及自动联网检测。源码运行模式修正进程助手路径；同步辅助脚本和采集组件依赖许可。程序内部版本仍为 0.1.0，使用日期 tag 区分本次快照。

限制：现有 JavaScript 是提取构建，不是完整原始 TypeScript/React 工程；进程助手目前只有二进制，尚未找到其 C# 原始源码。原有 `recovered-src` 为机械拆分片段，不能独立编译。界面为中文，文档为中英文。传感器、ETW 权限和硬件支持会影响数据可用性。Windows 包未经本次完整 GUI 回归验证。

用户数据仍在本机保存；主动配置 Telegram 后，相关消息会发送到 Telegram。公网 IP/连通性检测自动联网，测速由用户启动。因此不能宣称程序“绝不联网”或“所有数据绝不离开本机”。

更新前退出程序并备份本地数据，使用完整 ZIP 解压到新目录。本次没有设计数据迁移；仍建议保留旧版和备份。SHA-256 见同版本附件。

## English

Synchronizes the current Windows application snapshot: process management, CPU/GPU/memory rankings, temperature views, Telegram alerts and recovery notifications, button menus, status/network/energy queries and alert settings, plus appearance and shutdown changes.

Adds bilingual user guides and a dedicated updates/downloads entry. Privacy documentation now covers Telegram payloads, independent switches, and automatic connectivity checks. Fixes the process-helper path when running from the repository; includes helper scripts and process collector dependency licenses. The internal version remains 0.1.0; the dated tag identifies this snapshot.

Limitations: the JavaScript is an extracted build, not the complete original TypeScript/React project. The process collector currently has only a binary; its original C# source was not found. `recovered-src` contains mechanically split fragments that cannot compile independently. UI is Chinese; documentation is bilingual. Sensors, ETW permissions, and hardware support affect data availability. This Windows package has not undergone a complete GUI regression test in this publication session.

User data is stored locally; configuring Telegram allows related messages to be transmitted to Telegram. Public-IP/connectivity checks run automatically and speed tests are user-initiated. The application must not be described as never connecting or as keeping every piece of information exclusively on the PC.

Quit and back up local data before extracting the complete ZIP into a new directory. No migration is designed for this snapshot; retain the previous version and backups. See the release attachment for SHA-256 checksums.
